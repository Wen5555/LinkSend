# Security

设备身份是长期 Ed25519 公钥。邀请是短时、单次、高熵令牌，服务器只存摘要。服务器组成员关系不会自动产生本地信任；首次配对必须核对完整公钥指纹并写入 `trust.json`。撤销会关闭该设备的 WSS 和活动会话。

QUIC 使用 TLS 1.3、自签 Ed25519 证书和固定对端公钥，验证证书用途、有效期、URI 身份和自签签名。0-RTT 关闭。不存在无条件 `InsecureSkipVerify` 或信任所有证书的路径。

服务器日志和诊断不得记录私钥、邀请令牌或文件内容。候选仅允许已授权会话，拒绝广播、组播、link-local 和默认 loopback。限流、候选上限、会话上限和消息过期由服务端与协议层共同执行。

信令和 STUN 仍可看到在线时间与网络地址；项目不宣称服务器完全不知道元数据。Relay 能力固定为 `relay=false`，直连失败必须报告，不会回退到文件中继。
