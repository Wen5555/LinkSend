# Mac 原生冒烟测试单

以下步骤针对本轮 DMG，需一台真实 macOS 设备和一台已加入香港设备组的 Windows 对端。CI 编译或进程短暂存活不能替代本清单。

1. 核对 `SHA256SUMS.txt`，挂载 DMG 并将 `LinkSend.app` 拖入 `/Applications`。
2. 启动应用，确认设置页显示香港正式入口 `https://linksend.oooai.de`；新 profile 输入 `orion123`，确认真实加入后设备列表出现同一组成员和管理员权限证据。固定码只用于本轮测试，未来可能关闭。
3. 使用管理员设备生成动态一次性邀请码，在第二台设备加入；重复消费和过期码应拒绝。
4. 双端逐字核对完整设备指纹并点击“验证并信任”，确认“成员已加入”“对端在线”“直连已建立”分开显示。
5. Windows→Mac 与 Mac→Windows 各传输中文文件名、多层目录和大文件；接收端核对发送者、摘要、数量、目标目录后分别接受和拒绝，检查进度、SHA256 和完成后打开目录。
6. 在连接中取消，确认任务进入取消终态；失败后使用“重新发送”。当前没有 pause/resume，重试等价于重新发送。
7. 活动任务期间点击红点、Cmd+Q 和菜单退出，确认退出保护；选择继续时任务保持运行，选择取消并退出后资源有界释放。再次启动确认已加入凭据和信任关系保留。
8. 检查原生文件/目录选择器的取消、中文/空格路径和权限错误；窄窗口下导航折叠、按钮可点击、重要文本不裁切，并在“减少动态效果”系统设置下确认内容仍可用。

本机未具备 macOS 时，以上全部标记 `BLOCKED_BY_EXTERNAL_ENV`，不能以 Windows 浏览器截图或 CI 结果代替。
