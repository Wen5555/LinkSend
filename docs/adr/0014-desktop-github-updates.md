# ADR 0014：从 GitHub 检查和下载桌面更新

日期：2026-10-18。状态：用户要求的软件内更新功能，已随[0.6.2](../RELEASE-v0.6.2.md)发布。

## 用户流程

在“设置 → 软件更新”点击检查更新，读取`Wen5555/LinkSend`的GitHub最新正式Release；发现更新后点击下载，再点击打开安装包。显示当前版本、最新版本、更新说明、下载进度及取消入口。离开页面后下载继续，回到页面读取Go中的真实状态；退出应用取消未完成检查/下载。

Windows amd64使用官方NSIS安装程序，macOS按arm64/amd64选择DMG。包打开后先退出LinkSend（包括托盘后台），再完成安装并重新启动；已安装的Windows版本应选择原安装目录，便携版用户可以通过向导安装新版，原便携目录保留。Mac在DMG中将app拖入应用程序并确认替换。配置、配对和接收文件保持。页面提供应用退出按钮，仍走原有未结束任务保护。

本实现提供应用内检查、下载和原生安装入口；后台静默安装、自动覆盖运行程序、自动重启或回滚不在此次范围。已发布0.6.1包没有这个入口，首次使用需要安装包含该功能的新构建；不改写0.6.1的tag或资产。

## 代码与网络边界

`apps/desktop/updater`是独立于核心服务的桌面模块，使用Go标准库HTTPS；启动、浏览设置和轮询状态均不访问GitHub，只有明确检查和下载才联网。信令不可达或核心初始化失败不影响此入口。前端只接收状态和进度，不接触包正文、下载URL参数或本地可执行路径；原生打开方法只能使用后端已验证的文件。

固定调用`https://api.github.com/repos/Wen5555/LinkSend/releases/latest`。只接受匹配仓库URL的非Draft、非prerelease、稳定`vMAJOR.MINOR.PATCH`版本；按数字比较，不把较旧Latest降级覆盖本机。无本机包时提供发布页，不选其他架构。关于页读取后端真实版本，移除写死的0.5.0。

包名必须符合当前发行流程的版本/平台/40位源码提交命名；资产须已上传、大小在1B–1GiB之间、具备有效SHA256 digest，且下载地址精确属于该仓库/标签/文件。初始元数据不允许重定向；包下载仅允许HTTPS及明确的GitHub资产域名，最多5次跳转，保留TLS证书校验，使用现有系统代理设置，不读取GitHub凭据或接入镜像。

元数据最多2MiB，更新说明最多32KiB且按纯文本展示。检查超时30秒、下载20分钟；正文只写入本机应用缓存的独立随机目录，先`.part`、校验大小和SHA256、刷盘后再更名。中断/校验失败清理本次文件，取消保持单一操作槽直到worker结束，旧结果不能覆盖新请求。打开前再次验证文件类型、大小和SHA256；发现变化则禁用打开并要求重新下载。主程序、profile与接收目录不参与缓存清理。

SHA256以通过HTTPS取得的GitHub资产摘要为依据，证明下载内容与该发布资产一致，不是独立发布者签名。Windows仍未签名、Mac仍为ad-hoc/未公证，系统安装提示和权限判断保持。

具体命令、真实GitHub下载摘要、构建产物及未验范围见[更新实施记录](../evidence/DESKTOP-GITHUB-UPDATES.md)。自动测试不启动安装器；原生安装覆盖/重启仍需对应系统现场验证。
