# ADR0009：目录预设、规则版本与草稿内容身份

日期：2026-10-18。状态：源码候选；准确包原生与物理双机另验。

## 契约

默认`source_selection=null`发送完整内容。可选版本1的`source`预设和最多32条自定义排除规则；Go统一规范化、匹配、遍历与正式准备，JavaScript仅编辑元数据。预设目录为`.git`、`node_modules`、`dist`、`build`、`target`、`bin`、`obj`、`.venv`、`venv`、`__pycache__`、`.cache`、`coverage`，在任意深度仅匹配目录。版本1规则含义保持固定，后续改变预设或匹配语义必须使用新规则版本。

路径分隔符规范化为`/`，所有平台均大小写敏感，Unicode要求NFC。支持`*`、`?`和独立路径段`**`；无斜杠规则匹配任意深度的名称，含斜杠规则相对每个所选目录根匹配，尾随`/`仅匹配目录并排除其后代。绝对路径、`..`、空段、控制字符、取反、括号/花括号扩展等拒绝，不声明gitignore兼容，不执行脚本。所选根目录始终保留为容器；单独选择文件时按其文件名匹配。

预览与正式清单共用`os.Root`遍历和匹配器，不跟随符号链接。显式选择的符号链接、包含范围内的链接/特殊文件、危险相对路径仍拒绝；排除子树不读取正文。预览计数排除后代时只读元数据，排除的链接计为文件条目、0正文大小，不跟随链接。重复/嵌套输入统一归并为外层所选目录，跨根重名仍由已有manifest冲突检查拒绝。

预览最多扫描100000条元数据，包含数量不能超正式manifest的10000条上限；桌面预览总期限2秒，展开列表最多200条。达到限额、取消或读取失败明确`complete=false`，已有部分统计不冒充完整。预览不哈希正文，也不冻结源文件；正式入队与派发继续核对实际内容和完整性。

## 持久化、身份与恢复

任务库由9升级10，沿用一致性备份、验证、flush及事务迁移。草稿和队列新增规范化`source_selection`，队列另存`draft_id/draft_revision`；旧行默认完整发送。桌面从Go持久草稿提交其精确版本。正式入队在哈希前及提交事务内核对该草稿的路径、目标、规则和revision；内容摘要、规则快照及草稿来源同一事务持久化。草稿后来清空不破坏相同请求的幂等收据。原生/CLI明确路径命令可继续不用草稿来源，但也使用同一Go准备与队列。

队列内容摘要在原有中立transfer ID的manifest身份之外，纳入规范化规则版本/预设/模式；同一request不能替换规则，即使当前文件集合恰好相同。派发使用该快照，每次核对当前源。既有队列不因主草稿恢复完整发送而改变，源变化的显式再确认也保持原筛选规则。

带筛选的发送恢复记录用本地`version=2`，规则和原manifest/transfer身份同一task记录持久化；普通完整内容继续version1。暂停、应用重启、失败重试、历史重发都沿用保存规则，不能重新纳入排除内容。未支持规则或无效持久化数据拒绝，不能降为完整发送。入选文件或其有效元数据改变仍要求确认；保守校验也可能因根目录mtime变化要求确认，不声称冻结快照。

旧schema9客户端明确拒绝10的任务库，不能读取/恢复升级后的草稿和队列，不做自动降级；迁移前可读备份保留。恢复批次e43043d实际保持的是任务库9，ADR0008先前写7的笔误已按该提交history.go纠正。本ADR的10是新的N1变更。

## 网络与权限

文件wire V1、manifest V1、membership_v2、trust与控制库保持。接收端看到实际选中文件的正常manifest，可继续使用现有接收计划；本地排除规则不发送给信令或接收端。Go仍用原Pion/QUIC、固定身份pin、授权代次、hash与安全落盘。队列快照不授予新权限，也不通过JavaScript/Wails IPC传正文。
