# ADR0011：进程级文件正文预算

日期：2026-10-18。状态：源码候选与本地回归通过，准确包/物理另列于[唯一TODO](../DESKTOP-EXPERIENCE-TODO.md)。命令和结果见[证据](../evidence/DESKTOP-AE-FILE-BUDGET.md)。

默认不限速；桌面偏好保存`file_send_bytes_per_second`，0为不限速，其余为1KiB/s至1GiB/s的整数。单位切换只改变界面换算，Go验证负数、过小与过大值，JSON超范围同样拒绝。偏好保持format1的可选扩展，旧偏好缺字段默认0；旧程序不支持此可选限速、回退后不能宣称仍限速，任务库11与文件wire保持。

单个进程共享一个Go文件正文token bucket，所有文件发送入口、队列、批次、恢复和重传使用同一预算，不增加并发。仅在文件body frame的数据段前扣费，控制头、确认/取消、ICE/QUIC与自动剪贴板独立通路不受该预算限制。不是UDP线上带宽上限，协议/TLS/QUIC重传/头部不按此精确计量；应用级文件块重传再次计费。

突发容量为速率的100ms，最少1KiB、最多64KiB；每次写入最多64KiB且不超过当前容量。闲置累积不超容量，动态非零修改不重置出新预算。保存成功后运行中与未来文件使用新值，已获准的一小块不能收回；改为不限速立即唤醒等待。等待可由task context取消，不持有队列、任务或偏好锁。暂停调度仅阻止下一项，暂停任务才打断当前传输。

`transfer.SendOptions.BodyBudget`只控制文件body frame数据段，保留原四字节长度头。全部实际请求块都会扣费，包括PreviouslySent标记的重传；原生content_v1内容不使用该文件预算，明确file fallback仍计入。`internal/app`的唯一进程预算由全部发送入口共享，创建任务/identity/profile不补新额度。数值保存采用既有桌面偏好分类CAS与原子文件替换，校验在写入前，成功后唤醒运行中的预算；磁盘保存失败不修改运行时。重启先验证并应用偏好再启动队列。

假时钟验证预算、上限、动态更新、共享与取消；wire夹具核对帧字节完全一致、正文与应用级重传计费且控制不计费。真实Pion/QUIC在256KiB/s下1MiB/16块首末间隔3.763s、接收hash一致；1KiB/s文件等待时独立剪贴板夹具7.129ms提交，Pause/Resume/Cancel无预算死锁。该样本只证明同机夹具，不是物理吞吐/延迟承诺。
