# Acceptance Matrix

Current candidate: product `0.2.0`, protocol V1, Wails 3 `v3.0.0-beta.18`. This matrix separates source implementation, automated evidence, and real-network validation. A loopback result is never counted as LAN or NAT acceptance.

| Area | Implemented source | Automated/current evidence | Target validation |
|---|---|---|---|
| Identity and trust | Ed25519 identity, invite, fingerprint pinning, revoke | identity/signaling negative tests pass | OOB fingerprint review on two real devices |
| Signaling | SQLite group, HTTP/WSS auth, presence, session/generation ownership, stale-handler cleanup, simultaneous-initiation arbitration, `relay=false`, product version health field | Local real-WSS lifecycle/race tests pass; `hk-main` isolated fixed service passes complete→immediate retry and reject→immediate retry | Hong Kong test main still runs old failing build until the documented `0.2.0` transaction completes |
| ICE and QUIC | Pion ICE over quic-go-owned UDP socket, automatic eligible-interface selection with explicit priority/exclusion, address-change invalidation, TLS 1.3 pinning, real terminal flush and redacted structured evidence | Windows real ICE+QUIC lifecycle/resume tests and race pass; prior physical Windows↔macOS LAN passes; independent Linux dual NAT with explicit UDP mapping passes 8 MiB while MASQUERADE-only returns `CHECK_TIMEOUT` | Public IPv6, physical network switch/sleep, and additional NAT types without fixed mapping; endpoint-dependent NAT remains FAIL with relay unavailable |
| File protocol | Manifest, BLAKE3 chunks, safe root staging, verified missing-block requests, commit records and resumable checkpoints | 12 MiB pause/resume and damaged-block retransmit, 8 MiB full-Service restart resume, source/peer mismatch and partial-commit tests pass over real QUIC | Process kill during physical cross-device transfer and receiver-committed/sender-unconfirmed physical test |
| Task persistence | schema 2 revision-guarded snapshot + private recovery, corrupt-row quarantine, pre-migration v1 backup | migration/backup/readability, stale attempt, persistence-failure and restart recovery tests pass | Long-duration multi-process/profile misuse is unsupported; deployment profile migration/rollback drill pending |
| CLI | identity, pairing, devices, trust, revoke, diagnostics, send, receive, persisted `status`, explicit in-process `resume` | CLI tests plus shared app direct/recovery integration pass; two isolated Linux profiles transfer through independent mapped NATs | Physical cross-device NAT without fixed mapping; cross-process pause/cancel intentionally not claimed |
| Desktop | Wails 3 `v3.0.0-beta.18` Pause/Resume/Cancel/accept bindings, revision-gated React task UI, and asynchronous native quit guard with the correct idle `ShouldQuit=true` contract | bindings generation, desktop `GOWORK=off` test/vet and frontend frozen install/typecheck/lint/8 tests pass; r2 Windows `WM_CLOSE` and macOS arm64 idle quit Apple Event both exit; each package created one real native window | Native file/directory dialogs, open-directory, active-task close dialog/cancellation, macOS red-dot and actual Cmd+Q keystroke, keyboard/accessibility and restart-recovery interactions |
| Packaging | Wails 3 Windows build/package and macOS dual-arch DMG scripts; explicit LinkSend NSIS metadata | r2 dirty-source Windows ZIP + NSIS installer and arm64/amd64 DMGs built; hashes and tools recorded; both DMGs mount, match target arch/bundle ID and pass strict ad-hoc codesign verification | Windows install/uninstall smoke, Developer ID signing, notarization, minimum-macOS runtime, Intel Mac launch, clean committed workflow build |
| Operations | Docker/Caddy/STUN-only examples, versioned healthz, redacted diagnostics | compose config parses; isolated coturn STUN Binding and local-CA HTTPS identity run in the dual-NAT lab; Hong Kong test main unchanged at this checkpoint | Docker engine, public HTTPS certificate positive/negative tests, TURN Allocate rejection, test-main backup/restore transaction |
| Race and static checks | No race-specific code bypass | `go vet ./...`, `go test ./...`, and Windows `go test -race ./...` with MinGW 16.2.0 pass; Stage 1B affected packages repeated 20 times | Repeat on CI and target OSes |

Current validation gaps are public IPv6, physical network switching/sleep, NAT types that need endpoint-independent mapping or relay, installer install/uninstall, signing/notarization, minimum-macOS runtime, and the native Windows/macOS interaction matrix beyond window creation/basic Windows close. Controlled independent dual NAT is now PASS only for the explicitly mapped positive case; MASQUERADE-only remains a product FAIL (`CHECK_TIMEOUT`, relay not implemented). Pause, restart recovery and verified missing-block byte resume are implemented and locally validated; this does not retroactively make earlier packages or the old Hong Kong test binary capable.
