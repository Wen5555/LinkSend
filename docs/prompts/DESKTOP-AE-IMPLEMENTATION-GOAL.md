- 失败后用新证据改变假设，不原样无限重试。独立工作继续，只有真实需要人的条件才提出精确小问题，已有授权不反复索取。
- 上下文压缩/中断后从唯一TODO、当前diff、最后同步SHA、证据和jobPath继续；不从零重扫、不重复未知状态部署。阶段简报不等于停止，自动续行依赖平台Goal实际状态，不承诺未建立的后台监督。
- 每轮收尾留下：当前阶段/下一具体动作、分支与HEAD、最近push/CI、运行中job及资源所有权、失败与外部条件。只有A/B/B2/C/D/E必交付证据全部满足后标complete；真实阻塞保留未完成状态并按平台规则处理，不自改为“完成”。

## 12. 开始执行

先用少量只读检查固定当前现场与可用工具/主机，更新唯一TODO中本Goal工作包，选择A的最小真实复现并立即推进代码与测试；同时准备B的独立服务重建。不要只回复计划，也不要等用户再次说“继续”。

编写参考：[OpenAI官方 Using Goals in Codex](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)。本项目范围和授权来自用户当前请求与仓库契约；参考资料不扩张操作权限。
